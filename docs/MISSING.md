# What the Mudrix port still misses

Honest list of everything from the Mudrix port that is not done. Source: `docs/PORT.md` (inventory rows, "Port status",
"Android port status", "iOS port status", "Core calls wanted by P2-8 / P2-9", open questions) and
`git log --oneline main..HEAD` on `port/mudrix`. Row ids are PORT.md ids. Where something is not in PORT.md it says so.

Conventions. Size S / M / L is a rough effort guess (PORT.md's own size where it gave one). Priority is a judgement
call, not from PORT.md: P1 = affects daily use, P2 = noticeable gap, P3 = nice to have or niche. "Blocked by" says what
must exist first (a core call, a Mac, a device, a release). A row that is `partial` below is only listed for the part
that is missing.
