## Fixed

### Desktop

- Attachments save through the system dialog.
- Files can be dragged in from Explorer.
- Notifications and read receipts follow the window again.

### iOS

- Room layout, bubble colours and the gallery are fixed on iOS.
- The compact message layout can be chosen on iOS again.

### Interface

- Direct message rows, the nameplate scrim and the settings layout are tidier.
- Message links are underlined in the accent colour.
- Nameplate rows line up with the rest of the list.
- One direct messages header, without the duplicate New message pill.
- The phone's direct messages header is one row: search, inbox and +; sorting moved into the + menu.
- Reactions sit closer under the message, room switches glide instead of sliding, and the appearance previews call the demo user Muddy.

### Other
